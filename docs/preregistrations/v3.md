# degradomap v3 — Preregistration

**Date registered:** before running v3 analysis, April 2026.

## Hypothesis
If v1 features capture any real signal, they should rank post-2024 PROTAC E3s (held out from training) above median without retraining.

## Held-out set
5 proteins published as PROTAC E3s after our data collection cutoff: DCAF11, RNF126, FBXO22, TRIM21, STUB1.

## Pass criterion
At least 3 of 5 held-out E3s rank in the top 50% of the full E3 universe (rank ≤ 435 of 870).

## Analysis plan
Score held-out proteins with v1 model trained on original 12 positives. No retraining permitted.

## Result
**Partial pass (2/5).** TRIM21 (~rank 190) and STUB1 (~rank 210) passed. DCAF11 (~350), RNF126 (~280), and FBXO22 (~420) did not. Mechanism-specific: pocket binders generalize weakly; covalent binders do not. Pre-registered 3/5 threshold not met.
