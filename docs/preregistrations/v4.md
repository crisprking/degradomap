# degradomap v4 — Preregistration

**Date registered:** before running v4 analysis, April 2026.

## Hypothesis
WD40 β-propeller folds (e.g., DCAF11) are poorly represented by our current structural features, which are designed for globular proteins with deep pockets. Adding propeller-specific features (top-face hydrophobicity, top-face cleft depth, Cys proximity to top-face) will improve discrimination of propeller-fold PROTAC E3s without increasing false positives across the WD40 family.

## Primary test
DCAF11 LOO percentile improves from ≥40% (current) to ≤20% (pass criterion) with propeller features added.

## Secondary test (safety check)
The number of non-E3 WD40 proteins in the top-20 predictions does not increase by more than 3 compared to v1.

## Analysis plan
Compute 4 propeller features from AlphaFold structures for all proteins. Retrain v1 model with features added. Run LOO-CV.

## Result
**Catastrophic failure.** DCAF11 LOO rank improved (percentile ~10%) but the safety-check failed catastrophically: 11 additional non-E3 WD40 propeller proteins entered the top-20. The fold-family shortcut completely invalidated the primary result. This is a documented failure; the feature set is preserved in `src/degradomap/propeller.py` with warning.
