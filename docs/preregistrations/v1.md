# degradomap v1 — Retrospective preregistration

**Note:** v1 was exploratory. This document is a retrospective record.

## Question
Can AlphaFold-derived structural druggability features combined with DepMap essentiality and expression breadth discriminate the 12 published PROTAC E3 ligases from ~870 other human E3 ligase candidates?

## Positive set
12 proteins: VHL, CRBN, MDM2, BIRC2, BIRC3, XIAP, DCAF15, RNF4, RNF114, FEM1B, DCAF1, KEAP1.

## Features
10 structural features (compactness, hydrophobic patch area, pocket cluster count, pLDDT-weighted variants) + 4 DepMap features (mean Chronos, fraction essential, mean log TPM, fraction expressed).

## Model
Logistic regression, balanced class weights, leave-one-out cross-validation over positive set. Metric: LOO AUC.

## Result
Best LOO AUC = 0.587 (biological features alone). Combining structural + biological did not improve over biological alone. Top-ranked predictions: SKP1, ELOB, DDB1 (core UPS machinery, not novel E3 candidates).
