# degradomap v5 — Preregistration

**Date registered:** before running v5 analysis, May 2026.

## Hypothesis
The v2 covalent positive set (n=4) was homogeneous (3 RING + 1 multi-domain), which enabled the v4 fold-family shortcut. Expanding to 6 covalent positives spanning 4 structural folds (RING, WD40, F-box/LRR, multi-domain) will allow the model to learn covalent-site chemistry rather than fold membership.

## Positive set (declared before analysis)
- RNF4 (P78317) — RING-type, Ward et al. Cell Chem Biol 2019
- RNF114 (Q9Y508) — RING-type, Spradlin et al. Nat Chem Biol 2019
- DCAF1 (Q9Y4B6) — multi-domain, multiple 2022–2024
- DCAF11 (Q8TEB1) — WD40 propeller, Tin et al. BMCL 2024
- RNF126 (Q9BV68) — RING-type, Lim et al. ACS Cent Sci 2024
- FBXO22 (Q8NEZ5) — F-box/LRR, Nie et al. Nat Chem Biol 2024

Exclusions (declared before analysis): FEM1B (missing DepMap data), DCAF16 (<30 confident AlphaFold residues).

## Pre-registered tests (in priority order)

**PRIMARY:** Median LOO percentile across all 6 positives ≤ 25%.

**SECONDARY:** Multi-domain Spearman correlation (domain count vs LOO rank) ρ > 0.15, p < 0.05.

**TERTIARY:** DCAF1 (most complex fold) structural-only LOO percentile ≤ 50%.

**QUATERNARY:** Structural-only top-15 contains ≥ 10 proteins confirmed as E3 ligases (by literature, not by being in training set).

**ABLATION (exploratory, not pass/fail):** Compare full model vs structural-only model per positive to characterize shortcut mechanism.

## Results

| Test | Result |
|------|--------|
| PRIMARY (median LOO ≤ 25%) | **FAIL** — median 30.4% |
| SECONDARY (Spearman ρ > 0.15) | **FAIL** — ρ = 0.11, p = 0.18 |
| TERTIARY (DCAF1 struct ≤ 50%) | **FAIL** — percentile = 72.8% |
| QUATERNARY (top-15 ≥ 10 E3s) | **FAIL** — 7 E3s, 5 UPS scaffolds, 3 non-UPS |

Ablation: biological features create UPS-pathway shortcut (RING positives improve with bio features; newer non-essential positives worsen). Structural-only model is more honest but still discriminates poorly.

## Interpretation

Public-data features cannot solve the covalent PROTAC E3 problem. The next step requires: CysDB cysteine reactivity scores, competitive ABPP data, or AlphaFold-predicted Cys accessibility + electrophilicity proxies (pKa modeling, oxidation propensity).
