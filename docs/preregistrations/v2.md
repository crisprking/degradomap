# degradomap v2 — Preregistration

**Date registered:** before running v2 analysis, April 2026.

## Hypothesis
Pooling mechanistically heterogeneous PROTAC E3s (pocket binders, molecular glues, covalent binders) into one positive class erases mechanism-specific signal. Splitting by mechanism will reveal sub-class-specific feature importance.

## Primary test
Run LOO-CV separately within each mechanism class. Pass criterion: at least one mechanism class achieves LOO AUC ≥ 0.70.

## Secondary test
At least one feature shows a statistically significant (p < 0.05 by Mann-Whitney U, uncorrected) difference between positives and negatives within at least one mechanism class.

## Analysis plan
Classify all 12 positives into pocket_binder / molecular_glue / covalent (see `src/degradomap/mechanism.py`). Run LOO-CV per class using v1 features. Permutation test (1000 iterations) for each sub-experiment.

## Result
**Null.** No mechanism class reached LOO AUC ≥ 0.70. Covalent sub-experiment showed highest AUC (~0.61) but did not pass the pre-registered threshold. Permutation tests confirmed all results consistent with chance.
